# Rock_Paper_Scissor_Game

# 🎮 Rock, Paper, Scissors Game

A simple **Rock, Paper, Scissors game built with Python**.
The player chooses Rock, Paper, or Scissors, and the computer randomly selects its choice. The winner is decided according to the standard game rules.

## 📌 Project Overview

This project is a beginner-friendly Python game designed to practice:

* Python user input
* Conditional statements
* `while` loops
* Lists
* The `random` module
* Input validation
* Exception handling
* Basic game logic

## 🎯 Game Rules

The game follows these rules:

* 🪨 **Rock beats Scissors**
* ✂️ **Scissors beats Paper**
* 📄 **Paper beats Rock**
* 🤝 If both choices are the same, the result is a **Tie**

## 🛠️ Technologies Used

* **Python 3**
* **Jupyter Notebook**
* Python `random` module

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Nasarhussainsk/Rock_Paper_Scissor_Game.git
```

### 2. Open the notebook

Open:

```text
Rock,Paper,Scissor Game.ipynb
```

using **Jupyter Notebook** or **JupyterLab**.

### 3. Run the code

Run the code cell and enter one of the following choices:

```text
rock
paper
scissors
```

After each round, the game asks:

```text
Do you want to play again? (yes/no)
```

Enter `yes` to continue or any other response to exit.
